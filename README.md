# 講義まとめノート

大学の講義ごとに要点・練習問題・テスト対策をまとめた、個人の学習ノート集。

- トップ（`index.html`）：講義一覧のホーム画面
- 講義ごとのノートはフォルダ分けして置く。講義を増やすときはフォルダを作り、トップの一覧に1件追加する

## 収録している講義

### 複素数と正弦波 中間対策ノート（`kiso-math/`）

大学の数学の授業（第1〜8回：関数、微分とマクローリン展開、複素数とオイラーの公式、複素正弦波、システムの周波数特性、周波数スペクトル）の中間テスト対策用に作った、個人の学習ノート。

- 各回の要点まとめ（覚える → わかる → 注意 → 解く）
- 練習問題と解答、模擬テスト2回分
- 赤シート機能、「解けた」チェック（進捗はブラウザにだけ保存）

内容は自分なりにまとめたもので、問題はすべて自作。講義資料そのものは含んでいない。

### 微分積分 テスト対策ノート（`calculus/`）

微分積分の授業（第1〜5週：導関数・高階導関数、テイラー展開、極限、増減表と極値、ロピタルの定理、グラフの概形）のテスト対策ノート。

- 公式まとめ、各週の演習の解答と解き方、頻出パターンと落とし穴
- 模試2回分（タイマーつき）、練習問題、直前チェックリスト（チェックはブラウザにだけ保存）

### 電気回路 中間対策ノート（`denki-kairo/`）

電気回路及び演習Ⅰの中間試験対策ノート（試験範囲のスライド ec1〜ec6、演習問題1〜6）。

- 章ごとのまとめ（回路素子と直流回路、正弦波交流、インピーダンスとアドミタンス、フェーザ）
- 演習1〜6の全解答（回路図・フェーザ図つき）、類題の演習問題2（18問）、模擬試験2回分（タイマーつき）、公式シート、直前チェックリスト（チェックはブラウザにだけ保存）
- 例題・演習の数値はすべて計算し直して確認済み
